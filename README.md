**My answer: 271 tabs.**

One number, digits only — the count of open browser tabs. 271 is an odd,
non-round, prime number: the kind of total a real tab hoarder actually has
open across several windows, high enough to surprise and specific enough to
read as a genuinely counted pile. See `CANDIDATES.md` for the full candidate
study and why 271 was picked over the other numbers.

## How to run

```sh
python3 main.py
```

This writes `271` to `/output/entry.txt` — a single number, digits only,
nothing else.

## Files

- `main.py` — pure-stdlib Python 3.13; holds the chosen count, validates it
  (digits only, 1–5 characters), and writes it to `/output/entry.txt`.
- `CANDIDATES.md` — nine candidate numbers scored against the judge's brief,
  with the winner marked.
